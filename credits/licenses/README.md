# License texts

Full, verbatim copies of the licenses referenced by [`../credits.json`](../credits.json)
and [`../../CREDITS.md`](../../CREDITS.md).

**Convention:** name each file by its SPDX identifier — `GPL-2.0.txt`,
`CC-BY-4.0.txt`, `CC-BY-SA-4.0.txt`, `ODbL-1.0.txt`, etc. Entries reference them
via their `license_file` field.

**What needs a file here:** anything with real redistribution obligations —
copyleft (GPL, LGPL, MPL), attribution-share-alike (CC-BY-SA, ODbL), and any
bundled binary's license (OpenSCAD's GPL-2.0 goes here **before** we ship it).
Permissive in-tree licenses (MIT addons) already keep their own `LICENSE` file
next to the code, so they don't need a duplicate here — reference the in-tree
path instead.

License texts are meant to be redistributed verbatim; copying them here in full
is correct and expected.
